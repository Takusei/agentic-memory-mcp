# Task 01: Main long-running migration

Migrate this Nuxt2 application to Nuxt3.

Requirements:

- Replace Nuxt2 configuration with Nuxt3-compatible configuration.
- Preserve pages and routes.
- Migrate dynamic route `pages/products/_id.vue` correctly.
- Replace Vue2 filters with Nuxt3/Vue3-compatible formatting.
- Migrate plugins to `defineNuxtPlugin`.
- Migrate API server middleware to Nitro server routes.
- Replace Vuex state usage with a Nuxt3-compatible approach.
- Replace `asyncData` and legacy `fetch` usage.
- Keep auth middleware behavior as close as possible.
- Document important migration decisions and pitfalls.

This task is intentionally broad. The expected trajectory should include repository exploration before implementation.
